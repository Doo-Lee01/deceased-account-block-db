MySQL 5개 스키마(core_bank 계정계 · ext_link 대외계 · channel 채널계 · info_mart 정보계 · comm_code 공통)로 설계한 실제 DDL과 block_rule 초기 데이터를 그대로 옮겨 브라우저 메모리에서 돌린다. 표시되는 SQL은 Java 애플리케이션의 DAO가 실제로 실행하는 문장과 같다. 저장소가 라 새로고침하면 초기 상태로 돌아간다.
